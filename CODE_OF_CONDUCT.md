# Code of Conduct

## Our Commitment
We are committed to providing a welcoming, respectful, and harassment-free environment for everyone participating in this project, regardless of age, background, experience, identity, or beliefs.

## Expected Standards
- Treat all contributors and users with courtesy and respect.
- Provide constructive feedback and accept critique gracefully.
- Focus on what is best for the project and community.

## Enforcement
Maintainers review reported conduct issues fairly. Concerns can be submitted confidentially via GitHub Security advisories or private issue channels.
